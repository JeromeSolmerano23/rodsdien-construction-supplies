# Rodsdien Construction Supply — Frontend Demo

## Run locally
1. Extract the ZIP file.
2. Open the `rodsdien-construction-supply` folder.
3. Double-click `index.html` or open it with Chrome/Edge.

No installation, backend, database, API, or payment gateway is required.

## Included pages
- `index.html` — Dashboard and sample sales summary
- `products.html` — Product catalog, search, category filter, details
- `pos.html` — POS cart, quantity controls, checkout simulation
- `orders.html` — Sample orders and editable order status
- `inventory.html` — Stock levels, stock-in and stock-out adjustments
- `about.html` — Business background and contact placeholders

## Notes
- Sample product data and prices are in `app.js`.
- Cart and order demo data are saved in browser `localStorage`.
- Product stock changes are in-memory for the current page session; this is a UI demonstration, not a persistent inventory backend.
- Product photos are loaded from Unsplash, so an internet connection is needed for those images.
- Replace contact placeholders and verify sample prices before presenting.
